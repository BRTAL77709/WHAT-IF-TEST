# WHAT IF MONEY GREW ON TREES?

Original 78-second vertical 3D miniature-city film.

The finished H.264 MP4 is distributed as a GitHub Release asset named `WHAT_IF_MONEY_GREW_ON_TREES_FINAL.mp4`, under tag `v1.0-video`. Generated video, audio, Blender files and image sequences are excluded from Git history.

Video: 1080 × 1920, 30 fps, 2,340 frames, English narration and subtitles, stereo AAC audio.

The `WHAT_IF_MONEY_GREW_ON_TREES/` directory contains Python production sources, narration, captions, and reproduction documentation. The production reused existing Blender, Python and FFmpeg/Flite tools.
