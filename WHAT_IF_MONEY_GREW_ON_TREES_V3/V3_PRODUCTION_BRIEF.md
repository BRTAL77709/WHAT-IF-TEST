# SECTION 21 — PREDICT FAILURES BEFORE RENDERING

Before full rendering, identify likely failure points.

## Character runs in place

Cause: Missing root displacement.

Fix: Synchronize root translation with stride length and cadence.

## Feet slide

Cause: Incorrect stance constraints.

Fix: Maintain stable world-space foot targets during planted phases.

## Hand separates from money

Cause: Incorrect parenting or constraint blending.

Fix: Use stable grip targets and preserve transforms.

## Money teleports

Cause: Inconsistent object parenting or world coordinates.

Fix: Use continuous object trajectories and validated attachment transitions.

## Money passes through tree

Cause: Incorrect trajectory or missing collision clearance.

Fix: Adjust animation path without changing tree geometry.

## Character intersects counter

Cause: Invalid root path or collision avoidance.

Fix: Repair character movement and contact targets.

## Camera clips through building

Cause: Invalid camera trajectory.

Fix: Reposition the camera in valid free space.

## Camera loses the subject

Cause: Incorrect tracking target or camera orientation.

Fix: Repair tracking while preserving intended composition.

## Video flickers

Cause: Rendering, lighting, or geometry instability.

Fix: Identify the source and repair only the defect.

## MP4 is technically valid but motion is poor

Cause: Validation only checked file metadata.

Fix: Inspect actual continuous animation and correct source-level movement.
